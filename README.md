# MapBerlin

Kurzbeschreibung
-----------------
MapBerlin ist eine kleine Webanwendung zum Verwalten und Visualisieren von Orten (Locations). Benutzer können sich anmelden und vorhandene Locations auf einer interaktiven Karte betrachten. Administratoren können zusätzlich neue Locations anlegen, bestehende bearbeiten oder löschen; alle Daten werden in einer MongoDB-Datenbank gespeichert.

Verwendete Technologien
-----------------------
- Express — Backend und REST-API
- MongoDB 
- JavaScript 
- Leaflet + OpenStreetMap — Kartenanzeige und Marker
- Tailwind CSS
